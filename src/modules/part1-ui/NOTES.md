# แผนงานและ Checklist สำหรับโมดูล UI & Theme (คนที่ 1)

**โฟลเดอร์รับผิดชอบ:** `src/modules/part1-ui/`  
**Branch:** `feat/m1-shell-idb`

---

## 🎯 วัตถุประสงค์ (Goals)
1. **ออกแบบ UI / Theme ใหม่**: รองรับธีมสว่างและมืด (Light / Dark Mode)
2. **ตกแต่งตารางเรียน**: ปรับสีสัน การจัดวาง และการแสดงผลให้สวยงาม อ่านง่าย
3. **ระบบจำรูปพื้นหลังถาวร (IndexedDB)**: ผู้ใช้สามารถอัปโหลดภาพพื้นหลังตาราง และบันทึกลงใน IndexedDB ของเบราว์เซอร์เพื่อให้โหลดขึ้นมาใหม่ได้เสมอ
