# Public-PROJ — โครงสร้างเว็บตั้งต้นสำหรับทีม 5 คน (ม.อ. จัดตารางเรียน รุ่นใหม่)

คลังนี้เป็น **โปรเจกต์ตั้งต้น (Starter Base)** แบบ Vite + React (`.jsx`) ที่แยกโฟลเดอร์ไว้ **5 ส่วนชัดเจน** เพื่อให้สมาชิกทั้ง 5 คนพัฒนาฟีเจอร์ของตนเองและส่ง **Pull Request (PR)** พร้อมกันได้โดยโค้ดไม่ชนกัน

> **สถานะตั้งต้นของเว็บใน `main`:** มีเฉพาะ **"ช่องค้นหารายวิชา"** และ **"กดเลือก Section เพื่อนำมาใส่/ลบออกจากตารางเรียน"** ยังไม่ได้ใส่ฟีเจอร์ตกแต่งตาราง, เช็คเวลาชน, แผนสำรอง หรือส่งออกไฟล์ เพื่อให้เป็นพื้นที่ให้แต่ละคนไปต่อยอด

---

## 1. วิธีรันเว็บในเครื่องของตัวเอง

```bash
# 1. ดึงโปรเจกต์ลงเครื่อง
git clone https://github.com/sunkinincode/publicProj.git
cd publicProj

# 2. ติดตั้งแพ็กเกจ (ทำครั้งเดียว)
npm install

# 3. เปิดหน้าเว็บสำหรับพัฒนา
npm run dev
```

| **`322-102`** | แคลคูลัส 2 (CALCULUS II) · 3 นก. | หาดใหญ่ (`01`) | **ต้องสอบผ่าน `322-101` มาก่อน**<br>• `Sec 01`: จันทร์/พุธ `09:00–10:50` (**ชนเวลาเรียน + ชน Midterm กับ `322-101 Sec 01`**)<br>• `Sec 02`: อังคาร/พฤหัส `09:00–10:50` (**จำกัดกลุ่มผู้เรียน: เฉพาะนักศึกษาวิศวะ ปี 1**)<br>• `Sec 03`: ศุกร์ `13:00–15:50` (ไม่ชนกับวิชาอื่น + เปิดทั่วไป) |
| **`895-001`** | พลเมืองที่ดี (GOOD CITIZENS) · 2 นก. | หาดใหญ่ (`01`) | **วิชา Online แบบมีเวลาเรียนชัดเจน**<br>• `Sec 01`: จันทร์ `10:00–11:50` (ONLINE LMS — **ชนคาบเกี่ยวกับ `322-101 Sec 01` + ชน Final กับ `322-102 Sec 01/02`**)<br>• `Sec 02`: พุธ `13:00–14:50` (ONLINE Zoom — ไม่ชนใคร) |

## 4. ขั้นตอนการทำงานด้วย Git & Pull Request (PR)

1. อัปเดตสาขาหลักให้ล่าสุดก่อนเริ่มงาน:
   ```bash
   git checkout main
   git pull origin main
   ```
2. แตก Branch ส่วนตัวของตัวเอง (ทำเฉพาะในโฟลเดอร์ส่วนของตัวเอง):
   ```bash
   git checkout -b feat/m3-timetable
   ```
3. แก้ไขโค้ดเสร็จแล้ว ทดสอบรัน `npm run build` ให้ผ่าน แล้วอัปโหลดขึ้น GitHub:
   ```bash
   git add .
   git commit -m "feat: add clash detection in timetable grid"
   git push -u origin feat/m3-timetable
   ```
4. เข้าไปที่หน้าเว็บ GitHub ของ `publicProj` แล้วกด **Compare & pull request** เพื่อส่งงานให้เพื่อนร่วมทีมตรวจและ Merge เข้าสู่ `main`
